Bank of Z – IBM Z Banking Application

A sample enterprise banking application built on IBM Z, demonstrating modern development practices, CICS/COBOL/DB2 architecture, and end-to-end build and deployment automation.

Program Reference
BNKMENU – Main Menu Program Reference documentation for the BNKMENU CICS COBOL program, the primary navigation hub of Bank of Z. Covers BMS screen handling, pseudo-conversational logic, option routing, and error/abend handling. CRDTAGY2 – Credit Agency Simulator Reference documentation for the CRDTAGY2 CICS COBOL program. Covers asynchronous credit scoring via CICS channels and containers, random score generation, deliberate latency simulation, and timeout behavior. DELACC – Delete Account Program Reference documentation for the DELACC CICS COBOL program. Covers RACF security checks, DB2 account record deletion, audit trail writing to PROCTRAN, communication area conventions, and abend handling.
